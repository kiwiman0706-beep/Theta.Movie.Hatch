シーズンのタイトルと、別の並び順（放送順・時系列順など）に対応しました。

- **シーズンのタイトル**：「シーズン 2 遊郭編」のように出します。タイトルは `tvshow.nfo` の `<namedseason number="2">…</namedseason>` か、`Season 02/season.nfo` の `<title>` から読みます
- 整理前の `Season 02 遊郭編`・`Season 2 - 遊郭編`・`第2期 遊郭編` のようなフォルダも、2 期として読み、後ろをタイトルにします
- **別の並び順**：シリーズのフォルダに `放送順.m3u8`・`時系列順.m3u8` のようなプレイリストを置くと、作品の中に「並び順」が出ます。押すたびに切り替わり、選んだ順で一覧・続きから・次の話が進みます。動画は複製しません
- ファイル名規則（docs/naming-convention.md）を v0.3 に（3-4・3-5）
