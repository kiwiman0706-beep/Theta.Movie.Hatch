バックグラウンド再生と、VLC のようなジェスチャーを入れました。

**バックグラウンド再生**
- 画面を消しても、ほかのアプリに移っても再生が続きます
- 通知に操作ボタン（前の話・再生／一時停止・次の話）。ロック画面にも出ます。通知を押すとアプリに戻ります
- 再生中は、NAS から読み続けられるように端末と Wi-Fi を眠らせません（一時停止すると外します）
- 初めて再生するときに、通知の許可を聞きます（Android 13 以降）

**全画面のジェスチャー（VLC と同じ）**
- 左右になぞる：早送り・巻き戻し
- 左半分を上下になぞる：画面の明るさ（このアプリの全画面のときだけ。閉じると元に戻ります）
- 右半分を上下になぞる：音量（端末のメディア音量）
- 左右の端をダブルタップ：10 秒戻す・送る
- 長押し：倍速
