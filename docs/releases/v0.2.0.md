画面を Theta Music Hatch と同じ作り（Theta スキン＋クリックホイール）にしました。**再生しながら一覧を見て回れます。**

- 上にタブ付きの一覧（続きから・最近追加・棚ごと・探す・設定）、下に動画のパネルとホイール
- 一覧：棚 → 作品 → シーズン → 話。作品の中に、再生・続きから・最初から・あらすじ・出演者（同じ人の作品へ）・特典映像・関連作品
- 選んで中央ボタンで、パネルで再生が始まります。再生したまま一覧を動かせます
- 再生中のパネル（押すか、一覧のいちばん上で MENU）：回すと早送り・戻し（10 秒ずつ）、中央で音量に切り替え、◀◀ ▶▶ で前・次の話（長押しで早送り）、▶❚❚ で一時停止
- 全画面：中央ボタンの長押し・スマホを横にする・パネルをダブルタップ。全画面では音声（二か国語）・字幕の切り替え。縦に戻すとパネルに戻ります（再生は続きます）
- 話が終わったら次の話へ
- 長押しで「見た／まだ」を切り替え
- 設定にホイールのカリカリ音・振動・案内のオン・オフ
