最初の版です。NAS の動画を、変換せずに端末でそのまま再生します。

- NAS への接続：DSM の File Station（2 段階認証に対応）か WebDAV。Theta Home Hatch から設定を受け取れます
- 棚ごとのポスターの一覧、最近追加、検索（題名・出演者・監督）
- 作品の画面：あらすじ・出演・シーズンと話・バージョン・特典映像・関連
- 再生（mpv）：続きから、次の話、音声（二か国語）・字幕の切り替え
- 整理前のフォルダも、できるだけ作品にまとめて読みます
- スキンはシリーズ共通（Home Hatch に合わせる）。更新は Home Hatch に頼みます

実機ではまだ確かめていない点があります（TESTING.md）。
