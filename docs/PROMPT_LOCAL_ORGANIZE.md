# 動画の整理を、ローカルの Claude Code に頼む文

自分の PC（Windows か Mac）の Claude Code に、下の「---」から下を貼る。
NAS の共有フォルダ `8Tube` を PC にネットワークドライブとしてつないでおく（Windows なら例えば `Z:`）。
1 回で全部やろうとせず、**棚を 1 つ・フォルダを 1 つ**ずつ頼む。

---

NAS（Synology DS1825+）の動画を整理したいです。手伝ってください。

## 決まり

GitHub の `kiwiman0706-beep/Theta.Movie.Hatch`（公開）の **`docs/naming-convention.md`** に、並べ方・名前・整理の約束・整理の記録の形がすべて書いてあります。最初に全部読んでください。
https://github.com/kiwiman0706-beep/Theta.Movie.Hatch/blob/HEAD/docs/naming-convention.md
（読めなければ私に言ってください）

- 共有フォルダは DSM のパスで `/8Tube`、PC からは **＜例：`Z:\`＞** で見えています
- 今回やるのは **名前と場所だけ**（規則 §10 の 1）。NFO・ポスターは作らないでください
- 今回の対象：**＜例：`Z:\$StreamFab2\` の中のアニメ＞** → `/8Tube/▶アニメ/` へ

## 進め方

1. **調べる**：対象を読むだけで調べ、件数・形式・今の並び・問題（名前のゆれ、話数の抜け・重複、NFD の名前、使えない文字など）をまとめて見せてください。まだ何も動かさないでください
   - 動画の長さ・番組情報は `ffprobe` で（無ければ入れ方を教えてから。Windows は winget、Mac は Homebrew）
2. **スナップショット**：DSM で `/8Tube` のスナップショットを撮るよう、私に頼んでください（私が撮ります）
3. **変更案**：規則の形に合わせた変更案を CSV（元の場所・新しい場所・理由・確かさ）で作り、要点を表で見せてください。確かさの低い物は「要確認」にして私に聞いてください
   - 場所は **DSM のパス（`/8Tube/…`）で**書いてください（整理の記録にそのまま使うため）
4. **実行**：私が OK した物だけ、1 回数百件まで動かしてください。動かしたら、規則 §11 の形で **`/8Tube/_整理の記録/<日時>.csv`** を書き、**元に戻すスクリプト**も一緒に作ってください（元に戻したときも、逆向きの記録を新しい日時で残す）
5. **確かめる**：件数が合っているか（消えた物が無いか）を確かめて教えてください。最後に、Theta Movie Hatch で「NAS を読み直す」ように私に言ってください

## 守ってほしいこと

- **消さない**。重複・不明な物は `/8Tube/_未整理/` か一覧に回す
- **中身を変えない**（再エンコード・形式の変換・`.ts` → `.mkv` の詰め替え・タグの書き換えをしない）
- 動画と同じ名前の付属ファイル（`.nfo`・`.srt` など）は一緒に動かす。シリーズの `.m3u8` があれば中のパスも直す
- ▶ の付いていないフォルダ（`$StreamFab2` など）は、対象に言われた物以外は触らない
- 大きな処理は、まず 10 件くらいで試して結果を見せてから
- 道具は Python 3.12 で（入っていない物は入れ方を教えてから）
