# 動画ライブラリの整理ルール v1.1（Theta Movie Hatch）

> このファイル 1 つに、動画の並べ方・名前・付属ファイル・整理の手順と約束をまとめる（2026-11-18）。
> ローカルの Claude に整理を頼むときも、これだけを読ませればよい（頼む文：[`PROMPT_LOCAL_ORGANIZE.md`](PROMPT_LOCAL_ORGANIZE.md)）。
> Theta.Hatch.Series の `spec/THETA_LIBRARY_SPEC.md` から参照されているので、**このファイルの場所は変えない**。

目的：**Theta Movie Hatch が無くなっても、Jellyfin・Plex・Kodi・Infuse・VLC でそのまま読める**こと（業界の事実上の標準に合わせる）。

## 履歴

- v1.1（2026-11-19）：ミュージックビデオは 8Tube に置かない（`music` に移し、Theta Music Hatch で管理）
- v1.0（2026-11-18）：1 つのファイルにまとめた。共有フォルダ `/8Tube`・棚の目印 `▶`・独自の棚・放送局の一覧・整理の記録の形（§11）を決めた
- v0.3（2026-11-18）：シーズンのタイトル（§3-4）、別の並び順の `.m3u8`（§3-5）
- v0.2（2026-11-17）：アニメ映画を分ける、劇場版は映画に独立、アニメの期はシーズン、暗号化なし
- v0.1（2026-11-04）：最初の版

## 0. 基本

1. **フォルダ 1 つ＝作品 1 つ**（映画もシリーズも）
2. 作品は **`タイトル (年)`** で表す。年は最初の公開・放送年
3. 話数は **`S01E03`**（半角・2 けた）
4. 補足（放送日・放送局・DVD の枚数など）は **末尾の `[ ]`**。他のソフトは無視してくれる
5. 詳しい情報はファイル名に詰め込まず、**`.nfo` とポスター**に書く
6. **動画の中身は変えない**（再エンコード・形式の変換・`.ts` → `.mkv` の詰め替えもしない）。変えるのは名前と場所だけ

## 1. 共有フォルダと棚

- 動画の共有フォルダは **`/8Tube`**（DSM の File Station から見たパス。PC からはネットワークドライブ）
- その直下の、名前が **`▶` で始まるフォルダ＝棚**。Theta Movie Hatch は ▶ の付いたフォルダだけを読む（設定の「読むフォルダの目印」、既定 ▶）
- **▶ の無いフォルダは読まない**。整理前の物・ダウンロードの置き場（`$StreamFab2` など）・作業用はそのままでよい
- `_` で始まるフォルダ（`_整理の記録`・`_未整理`）は記録・置き場で、作品として読まない

| 棚のフォルダ | 中身 | 種類 |
|---|---|---|
| `▶映画` | 実写の映画（邦画・洋画）、ドラマの劇場版 | 映画 |
| `▶アニメ映画` | アニメの映画・劇場版 | 映画 |
| `▶ドラマ` | 連続ドラマ（国内・海外） | シリーズ |
| `▶アニメ` | TV アニメ・OVA・配信アニメ | シリーズ |
| `▶テレビ` | バラエティ・ドキュメンタリー・特番・ニュース | シリーズ（特番は §4-3） |
| `▶ライブ` | ライブ・舞台・コンサート | 映画 |
| `▶ホームビデオ` | 家族・自作の動画（スマホの動画は写真と一緒） | §7 |
| `▶<独自の名前>` | 例：`▶子供番組・知育・受験`。決まった棚に合わない物のまとまり | 中は映画・シリーズと同じ形 |

- **ミュージックビデオは 8Tube に置かない**（2026-11-19 決定）。PV・MV、ライブ映像の 1 曲分、YouTube の MV は共有フォルダ `music` に移し、**Theta Music Hatch で視聴・管理**する（Movie Hatch では扱わない）。決まりは Theta.Hatch.Series の `spec/THETA_LIBRARY_SPEC.md` §4.1
- 独自の棚を作ってよい（2026-11-18 決定）。中の作品の並べ方は映画（§2）・シリーズ（§3）と同じ
- **映画とシリーズを同じ作品フォルダに混ぜない**（他のソフトが読み違える）。独自の棚の中には混ざってよい（作品フォルダごとに形が決まっていれば読める）

```
/8Tube/
├─ ▶映画/
├─ ▶アニメ映画/
├─ ▶ドラマ/
├─ ▶アニメ/
├─ ▶テレビ/
├─ ▶子供番組・知育・受験/
├─ _整理の記録/          ← 整理のたびの記録（§11）。消さない
├─ _未整理/              ← 決められなかった物
└─ $StreamFab2/ …        ← ▶ の無いフォルダは読まない（そのまま）
```

## 2. 映画

```
▶映画/
└─ 君の名は。 (2016)/
   ├─ 君の名は。 (2016).mkv
   ├─ 君の名は。 (2016).nfo
   ├─ 君の名は。 (2016).ja.srt      ← 字幕（任意）
   ├─ poster.jpg
   ├─ fanart.jpg                     ← 背景（任意）
   └─ extras/                        ← 特典映像（任意）
      └─ メイキング.mkv
```

- **別のバージョン**は同じフォルダに：`君の名は。 (2016) - 4K.mkv`、`… - ディレクターズカット.mkv`（` - ` の後ろにバージョン名）
- **分かれたファイル**（DVD 2 枚組など）：`七人の侍 (1954) - part1.mkv`、`… - part2.mkv`
- **シリーズの劇場版**：映画の棚に独立した作品として置く（`▶アニメ映画/劇場版 〇〇 無限列車編 (2020)/`）。シリーズとのつながりは NFO の `<set><name>〇〇</name></set>`。シリーズの `Season 00` には入れない

## 3. シリーズ（ドラマ・アニメ・テレビ）

```
▶アニメ/
└─ 〇〇 (2019)/                        ← シリーズ名 (最初の放送年)
   ├─ tvshow.nfo
   ├─ poster.jpg
   ├─ Season 00/                       ← 特別編（SP・OVA・総集編・未放送話）
   │  └─ 〇〇 S00E01 OVA「サブタイトル」.mkv
   ├─ Season 01/
   │  ├─ 〇〇 S01E01「サブタイトル」.mkv
   │  └─ 〇〇 S01E02「サブタイトル」.mkv
   ├─ Season 02/
   │  └─ 〇〇 S02E01「サブタイトル」.mkv
   └─ extras/                          ← 特典映像・ノンクレジット OP/ED
```

### 3-1. 話の名前
`シリーズ名 SxxEyy「サブタイトル」 [補足].拡張子`
- サブタイトルは任意（あれば `「」`）
- 1 ファイルに 2 話：`〇〇 S01E03-E04.mkv`。100 話以上：`S01E100`

### 3-2. シーズン（アニメの期）
- **シーズン＝期・クール**。2 期の題名が違っても（「〇〇 続」「〇〇 第2期」）**同じシリーズの `Season 02`**
- 話数はシーズンごとに 1 から
- 番号は **TMDB の番号に合わせる**のを基本にする（Jellyfin・Plex が同じ番号で情報を取れる）。TMDB と放送の番号が違う作品は §3-5 の並び順で補う

### 3-3. 特別編
| 種類 | 置き場所 |
|---|---|
| SP・OVA・総集編・未放送話 | `Season 00/` |
| 劇場版 | 映画の棚に独立（§2） |
| 特典映像・ノンクレジット OP/ED | シリーズの `extras/` |

### 3-4. シーズンのタイトル
- フォルダ名は **`Season 02` のまま**（タイトルを足すと Plex などで読めなくなる）
- タイトルは NFO に（どちらか一方でよい。両方あれば `season.nfo` が優先）
  - `tvshow.nfo`：`<namedseason number="2">遊郭編</namedseason>`
  - `Season 02/season.nfo`：`<season><seasonnumber>2</seasonnumber><title>遊郭編</title></season>`
- 整理前の `Season 02 遊郭編`・`Season 2 - 遊郭編`・`第2期 遊郭編` は、`Season 02` に直し、タイトルは NFO に移す

### 3-5. 別の並び順（放送順・時系列順など）
同じ話を並びだけ変えて見たいとき（例：涼宮ハルヒの憂鬱）。**動画は複製しない。**
```
▶アニメ/涼宮ハルヒの憂鬱 (2006)/
├─ Season 01/ …
├─ 放送順.m3u8
└─ 時系列順.m3u8
```
- シリーズのフォルダの直下に `.m3u8`（UTF-8）。ファイル名が並び順の名前になる
- 中身は 1 行に 1 話、シリーズのフォルダからの相対パス（`Season 01/涼宮ハルヒの憂鬱 S01E01「…」.mkv`）。`#EXTM3U`・`#EXTINF:-1,題名` の行は付けてよい
- 動画の名前を変えたら、`.m3u8` の中のパスも直す

## 4. テレビ録画

### 4-1. 連続物（ドラマ・アニメの録画）
シリーズ（§3）と同じ形で、末尾に放送の情報：
```
▶ドラマ/〇〇 (2019)/Season 01/〇〇 S01E03「サブタイトル」 [2019-04-21 TBS].ts
```
- 補足は `[放送日 放送局]`、再放送は `[2019-04-21 TBS 再]`
- 放送局の略し方（2026-11-18 決定）：`NHK総合` `Eテレ` `NHK BS` `日テレ` `テレ朝` `TBS` `テレ東` `フジ` `TOKYO MX` `BS11` `BS日テレ` `BS朝日` `BS-TBS` `BSテレ東` `BSフジ` `WOWOW` `AT-X`。一覧に無い局は番組情報の局名をそのまま

### 4-2. 回ごとに独立した番組（バラエティ・ドキュメンタリー）
シーズン＝放送年、話数の代わりに放送日：
```
▶テレビ/〇〇の番組 (2005)/Season 2019/〇〇の番組 2019-04-07「今回の内容」 [テレ朝].ts
```

### 4-3. 単発の特番
映画と同じ形：
```
▶テレビ/特番名 (2019)/特番名 (2019) [2019-12-31 NHK総合].ts
```

### 4-4. 番組名・話数の手がかり
- `.ts` の中の番組情報（番組名・放送日時・説明）、ファイル名の日付・局、しょぼいカレンダー（アニメの放送日 → 話数）
- 決められない物は動かさず、変更案で「要確認」

## 5. DVD・BD から取り込んだ物

- 映画・シリーズと同じ形。出どころはファイル名に書かない（NFO の `<source>DVD</source>` は任意）
- ディスクの特典 → `extras/`
- 話の区切りが無い（ディスク 1 枚が 1 ファイル）：`〇〇 S01E01-E04 [DVD1].mkv`
- チャプター・字幕・音声はファイルの中のまま（変えない）

## 6. 付属ファイル

| ファイル | 名前 |
|---|---|
| 映画の情報 | `作品名 (年).nfo` |
| シリーズの情報 | `tvshow.nfo` |
| シーズンの情報 | `Season 02/season.nfo`（任意） |
| 話の情報 | 動画と同じ名前の `.nfo`（任意） |
| ポスター・背景 | `poster.jpg`・`fanart.jpg` |
| シーズンのポスター | シリーズのフォルダに `season01-poster.jpg`（特別編は `season-specials-poster.jpg`） |
| 字幕 | 動画と同じ名前 + `.ja.srt`・`.en.srt`、強制字幕は `.ja.forced.srt` |
| 別の並び順 | シリーズのフォルダに `<名前>.m3u8`（§3-5） |

- 動画の名前を変えたら、**同じ名前の付属ファイル（`.nfo`・`.srt` など）も一緒に**変える
- NFO・ポスターを作る（TMDB・Annict・Gemini で情報を取る）のは**整理の次の段階**（§10）

## 8. 文字

### 8-1. 使えない文字は全角に
| 半角 | 全角 |
|---|---|
| `:` | `：` |
| `?` | `？` |
| `/` | `／` |
| `\` | `＼` |
| `*` | `＊` |
| `"` | `”` |
| `<` `>` | `＜` `＞` |
| `|` | `｜` |

- 名前の最後にスペース・`.` を置かない。先頭に `.` を置かない

### 8-2. そろえ方
- **英数字は半角、カタカナは全角**（半角カナは使わない）
- スペースは半角 1 つ（全角スペース・連続スペースは使わない）
- `(年)`・`[補足]`・`S01E01` は半角
- 作品名の記号（`。` `！` `・` `〜`）は正式タイトルのまま
- Unicode は **NFC**（Mac で作った名前の濁点が分かれていたら直す）

### 8-3. 長さ
- ファイル名は 120 文字以内（`/8Tube` は暗号化していない。暗号化した共有フォルダなら約 47 文字）

---

## 9. タイトルの決め方

1. 日本で公開・放送されたときの正式タイトル（洋画は邦題）
2. 年は最初の公開・放送年（リメイクは別の作品・別の年）
3. 年が分からなければ年を付けず、変更案で「要確認」
4. 同じタイトル・同じ年の別作品があるときだけ、フォルダ名の末尾に `[tmdbid-12345]`。ふだん ID は NFO に書く

---

## 10. 整理の進め方（段階）

1. **名前と場所**（今回）：§1〜§9 の形に並べ替え、名前を変える。NFO・ポスターは作らない
2. **情報**（次）：TMDB・Annict・しょぼいカレンダー・Wikipedia＋Gemini で NFO・ポスター・シーズンのタイトル・並び順の `.m3u8` を作る
3. **Video Station から移す**：Video Station のデータベース（書き出し済み）の視聴済み・情報を、整理の記録（§11）で新しい場所に結び付けて移す

**整理を始める前に必ず：**
- Video Station のデータベースを書き出しておく（`docs/PROMPT_VIDEOSTATION_BACKUP.md`）。データベースは元の場所でファイルを覚えているので、整理の記録（§11）と合わせて移す
- Theta Movie Hatch を 0.3.3 以上にしておく（整理の記録を読んで、続きから・見た印を新しい場所に引き継ぐ）

---

## 11. 整理の約束と記録

1. 始める前に、`/8Tube` の **Btrfs スナップショット**を撮る（DSM の Snapshot Replication。撮るのは利用者）
2. まず **変更案の CSV**（元の場所・新しい場所・理由・確かさ）を作り、要点を見せる。確かさの低い物は「要確認」で、利用者に聞く
3. 利用者が OK した物だけ動かす。**1 回は数百件まで**、棚ごと・フォルダごとに
4. 動かしたらすぐ **整理の記録**を書く（下の形）。**1 つのコマンドで元に戻せる**スクリプトも作る
5. **消さない**。重複・不明な物は `_未整理/` か一覧に回す
6. **中身を変えない**（再エンコード・変換・タグの書き換えをしない）
7. 終わったら件数を確かめる（消えた物が無いか）。Theta Movie Hatch・Jellyfin は読み直す

### 整理の記録（Theta Movie Hatch が読む）

- 置き場所：**`/8Tube/_整理の記録/<日時>.csv`**（例 `20261118-213000.csv`。日時の順に読む）
- 文字コード UTF-8。1 行目は見出し `元の場所,新しい場所,理由`
- **1 列目・2 列目は DSM のパス**（`/8Tube/…` で始まる。PC のドライブ文字 `Z:\…` ではない）。区切りは `/`
- ファイルを動かしたら 1 行。**フォルダごと動かした・名前を変えた**ときはフォルダの 1 行でよい（中のファイルもまとめて付け替える）
- カンマを含む名前は `"…"` で囲む（中の `"` は `""`）
- **元に戻したとき**も、逆向き（新しい場所 → 元の場所）の記録を新しい日時の CSV で残す
- 記録は消さない・書き換えない（Theta Movie Hatch は、読み込んだ記録を覚えて二度当てない）

```csv
元の場所,新しい場所,理由
/8Tube/録画/ドラマ名 第1話.ts,/8Tube/▶ドラマ/ドラマ名 (2019)/Season 01/ドラマ名 S01E01 [2019-04-21 TBS].ts,番組情報と放送日から
/8Tube/アニメ/〇〇,/8Tube/▶アニメ/〇〇 (2019),フォルダごと
```
