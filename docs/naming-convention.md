# Movie Hatch ファイル名規則 v0.2

> v0.2（2026-11-17）：未決事項を決定（アニメ映画は分ける・シリーズの劇場版は標準の置き方・アニメの期はシーズン・暗号化なし）。Theta Movie Hatch 0.1.0 はこの規則で読む

目的：**Movie Hatch がなくなっても、Jellyfin / Plex / Kodi / Infuse など他のソフトでそのまま読めること**（ベンダーロックイン防止）。
業界の事実上の標準（Kodi/Jellyfin/Plex 共通部分）に沿い、日本語ライブラリ向けのルールを足したもの。

---

## 0. 基本方針

1. **フォルダ1つ = 作品1つ**（映画もシリーズも）
2. 作品の特定は **タイトル + (年)** で行う。年は「最初の公開・放送年」
3. 話数は **`S01E03`** 形式（半角・2桁ゼロ埋め）
4. 補足情報（放送局・放送日・画質など）は **`[ ]` で末尾に** 付ける。他のソフトは無視してくれる
5. 詳しい情報はファイル名に詰め込まず、**NFO と Markdown に書く**

---

## 1. ライブラリの最上位フォルダ

| フォルダ | 中身 | 種類 |
|---|---|---|
| `映画/` | 実写映画（邦画・洋画） | 映画 |
| `アニメ映画/` | 劇場版アニメ・アニメ映画 | 映画 |
| `ドラマ/` | 連続ドラマ（国内・海外） | シリーズ |
| `アニメ/` | TVアニメ・OVA・配信アニメ | シリーズ |
| `テレビ/` | バラエティ・ドキュメンタリー・特番・ニュースなど | シリーズ |
| `ライブ/` | ライブ・舞台・コンサート | 映画 |
| `ホームビデオ/` | 家族・自作の動画 | 自由形式（下記 7章） |

> 「映画」と「シリーズ」を同じフォルダに混ぜない（他のソフトが誤認識するため）。

## 2. 映画

```
映画/
└─ 君の名は。 (2016)/
   ├─ 君の名は。 (2016).mkv
   ├─ 君の名は。 (2016).nfo
   ├─ 君の名は。 (2016).ja.srt          ← 字幕（任意）
   ├─ poster.jpg
   ├─ fanart.jpg                         ← 背景画像（任意）
   └─ extras/                            ← 特典映像（任意）
      └─ メイキング.mkv
```

### 2-1. 複数バージョン（同じフォルダに置く）
```
君の名は。 (2016) - 4K.mkv
君の名は。 (2016) - ディレクターズカット.mkv
```
` - `（半角スペース・ハイフン・半角スペース）の後ろにバージョン名。

### 2-2. 複数ファイルに分かれている（DVD 2枚組など）
```
七人の侍 (1954) - part1.mkv
七人の侍 (1954) - part2.mkv
```

### 2-3. シリーズ物の映画（劇場版など）
- **映画フォルダに独立した作品として置く**（Jellyfin・Plex・Kodi の標準の置き方。2026-11-17 決定）。アニメの劇場版は `アニメ映画/`、ドラマの劇場版は `映画/`
- シリーズとのつながりは NFO の `<set>`（コレクション。名前はシリーズ名）で表す。Theta Movie Hatch は同じ `<set>` の作品を「関連」に並べる
- シリーズのフォルダ（`Season 00` など）には入れない

```
アニメ映画/
└─ 劇場版 〇〇 無限列車編 (2020)/
   ├─ 劇場版 〇〇 無限列車編 (2020).mkv
   └─ 劇場版 〇〇 無限列車編 (2020).nfo    ← <set><name>〇〇</name></set>
```

## 3. シリーズ（ドラマ・アニメ・テレビ）

```
アニメ/
└─ 〇〇 (2019)/                          ← シリーズ名 (最初の放送年)
   ├─ tvshow.nfo
   ├─ poster.jpg
   ├─ Season 00/                         ← 特別編（SP・OVA・総集編）
   │  └─ 〇〇 S00E01 OVA「サブタイトル」.mkv
   ├─ Season 01/
   │  ├─ 〇〇 S01E01「サブタイトル」.mkv
   │  ├─ 〇〇 S01E01「サブタイトル」.nfo
   │  └─ 〇〇 S01E02「サブタイトル」.mkv
   └─ Season 02/
      └─ 〇〇 S02E01「サブタイトル」.mkv
```

### 3-1. 話のファイル名
```
シリーズ名 SxxEyy「サブタイトル」 [補足].拡張子
```
- サブタイトルは任意。あれば `「」` で囲む
- 1ファイルに2話入っている：`〇〇 S01E03-E04.mkv`
- 100話以上：`S01E100`（そのままでOK）

### 3-2. シーズンの区切り方（アニメ）
- **シーズン = 期・クール**
- 2期のタイトルが違っても（例：「〇〇 続」「〇〇 第2期」）**同じシリーズの `Season 02`**（2026-11-17 決定）
- 話数はシーズンごとに1から数える
- データベース側（TMDB/Annict）と番号がずれる場合は、NFO と Markdown に対応を書く（ファイル名は自分のルールを優先）

### 3-3. 特別編
| 種類 | 置き場所 |
|---|---|
| SP・OVA・総集編・未放送話 | `Season 00/`（劇場版は入れない） |
| 劇場版 | `映画/` または `アニメ映画/` に独立（2-3） |
| 特典映像・ノンクレジットOP/ED | シリーズフォルダ直下の `extras/` |

---

## 4. テレビ録画

### 4-1. 連続物（ドラマ・アニメの録画）
**シリーズの規則（3章）に合わせ、補足に放送情報を付ける。**
```
ドラマ/〇〇 (2019)/Season 01/〇〇 S01E03「サブタイトル」 [2019-04-21 TBS].ts
```
- 補足の形：`[放送日 放送局]`、再放送なら `[2019-04-21 TBS 再]`
- 放送局は略称：`NHK総合` `Eテレ` `NHK BS` `日テレ` `テレ朝` `TBS` `テレ東` `フジ` `TOKYO MX` `BS11` など

### 4-2. 回ごとに独立した番組（バラエティ・ドキュメンタリー）
**シーズン = 放送年、話数の代わりに放送日。**
```
テレビ/〇〇の番組 (2005)/Season 2019/〇〇の番組 2019-04-07「今回の内容」 [テレ朝].ts
```

### 4-3. 単発の特番
```
テレビ/特番/特番名 (2019)/特番名 (2019) [2019-12-31 NHK総合].ts
```
映画と同じ扱い（`テレビ/特番/` は映画型のライブラリとして登録）。

---

## 5. DVD・BDから取り込んだもの

- **映画・シリーズの規則と同じ**。出どころはファイル名ではなく NFO/Markdown に記録（`source: DVD`）
- ディスクの特典映像 → `extras/`
- 話の区切りがない連続ファイル（ディスク1枚が1ファイル）：
  ```
  〇〇 S01E01-E04 [DVD1].mkv
  ```

## 6. 付属ファイル

| ファイル | 名前 |
|---|---|
| 映画の情報 | `作品名 (年).nfo` |
| シリーズの情報 | `tvshow.nfo` |
| 話の情報 | 動画と同じ名前 `.nfo` |
| ポスター | `poster.jpg` |
| 背景 | `fanart.jpg` |
| シーズンのポスター | シリーズフォルダに `season01-poster.jpg`（特別編は `season-specials-poster.jpg`） |
| 字幕 | 動画と同じ名前 + `.ja.srt` / `.en.srt`、強制字幕は `.ja.forced.srt` |
| Obsidian | 保管庫側に `映画/君の名は。 (2016).md`（フォルダ名と同じ） |

## 7. ホームビデオ

`年/日付 内容.拡張子`。人物・場所は Markdown のタグで管理。

## 8. 文字のルール

### 8-1. 使えない文字は全角に置き換える
Windows・SMB で使えない文字：

| 半角 | 置き換え |
|---|---|
| `:` | `：` |
| `?` | `？` |
| `/` | `／` |
| `\` | `＼` |
| `*` | `＊` |
| `"` | `”` |
| `<` `>` | `＜` `＞` |
| `|` | `｜` |

- 名前の最後に **スペースや `.` を置かない**
- 先頭に `.` を置かない（隠しファイル扱いになる）

### 8-2. 文字の統一
- **英数字は半角**、**カタカナは全角**（半角カナは使わない）
- スペースは **半角1つ**（全角スペース・連続スペースは使わない）
- `(年)` `[補足]` `S01E01` は半角
- 作品名の記号（`。` `！` `・` `〜` など）は**正式タイトルのまま**残す
- Unicode は **NFC** に統一（Mac で作ったファイル名は濁点が分かれた NFD になることがあり、Windows/NAS で別名扱いになるため）

### 8-3. 長さ
- ファイル名は **120文字以内** を目安
- ⚠️ Synology の **暗号化共有フォルダ** に置く場合は **143バイト（日本語で約47文字）** が上限。暗号化フォルダなら長いサブタイトルは省略する（いまの `video` は暗号化していない：2026-11-17 確認）

---

## 9. タイトルの決め方

1. **日本で公開・放送されたときの正式タイトル**（例：洋画は邦題）
2. 年は **最初の公開・放送年**（リメイクは別作品・別の年）
3. 年が分からない：年を付けずに置き、Markdown で `要確認` にする
4. 同じタイトル・同じ年の別作品がある：末尾に `[tmdbid-12345]` を付けて区別
   - 例：`〇〇 (2010) [tmdbid-12345]/`
   - Jellyfin はこの形の ID を読む。Plex の形は `{tmdb-12345}` で異なるので、**ID は基本的に NFO 側に書き、フォルダ名には衝突時だけ付ける**

---

## 10. 自動整理ツールの約束

1. 実行前に **Btrfs スナップショット**
2. まず **変更案の一覧（CSV）** を出す → 確認して承認したものだけ実行
3. 名前変更・移動はすべて記録し、**1コマンドで元に戻せる**
4. **削除はしない**
5. `.ts` → `.mkv` の変換はこの規則の対象外（字幕・二か国語音声が落ちる場合があるため、別途判断）
